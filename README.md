## 从零散材料，构建清楚的判断与论证

你可能已经有一堆资料、一份写到一半的报告，或一句不知道如何开口的话。思维架构师从对方最关心的问题出发，提炼中心判断，组织理由和证据，再适配文稿、演示或口头对话的形式。

**结论先行　·　以上统下　·　归类分组　·　逻辑递进**

完整写作、分析与审阅能力持续保留。实践学习贯穿其中：看见方法的出处，理解它如何起作用，再把它带到下一次真实沟通。

## 八大能力，覆盖完整表达场景

| 能力 | 具体支持 | 典型交付 |
| :--- | :--- | :--- |
| **短文与汇报** | 邮件、周报、摘要、简短说明；提炼进展、结论、请求与待决事项 | 可直接使用的短文或口头汇报 |
| **长文与报告** | 搭提纲、组织章节、展开方案与建议书、重组已有文稿 | 提纲、详细提纲、指定章节或全文 |
| **PPT 故事线** | 梳理整场主线，设计逐页观点、证据位置、图示与讲述要点 | 连贯故事线及按需展开的逐页设计 |
| **问题与决策分析** | 界定现状与目标差距，拆解原因假设，设计验证路径、比较方案 | 问题框架、验证计划、比较标准与条件性建议 |
| **逻辑审阅** | 检查结论、上下支撑、同层分组、重复与排序，定位实际结构问题 | 按影响排列的诊断与对应修法 |
| **来源与数据核对** | 对照材料核对数字、单位、口径与限定条件，区分事实、推断、计划与建议；重要计算用工具复核 | 核对结果、证据缺口及必要修订 |
| **日常沟通** | 商量安排、解释选择、请求帮助、说明误会、复述经历 | 适配关系与场景、能自然说出口的表达 |
| **方法学习与练习** | 理解结论先行、SCQA、MECE、归纳与演绎等，结合真实任务练习迁移 | 简短方法复盘、按需讲解与针对性练习 |

## 每一次表达，都积累为自己的能力

默认交付 **一份清楚的结果，一小段有用的复盘**。一次聚焦一个实际起作用的主要方法，通常几句话就讲清楚，需要深入时再展开。

| 学习支持 | 实际体现 |
| :--- | :--- |
| **方法有出处** | 点明实际用到的原理或框架，连接随附资料的对应章节；不堆术语或虚构书页。 |
| **原理讲得明** | 对照本次表达，解释为何先说这句话、这些理由为什么属于同一组。 |
| **迁移到生活** | 给出一个可复用的自问句或提示，连接下一次商量、请求、解释与汇报。 |
| **逐步独立运用** | 练习按需进行，重复使用时减少重复讲解；依据使用者自己的表现反馈。 |

产出清楚是眼前结果；能用自己的话解释结构，并换一个情境独立运用，是逐步内化的表现。

## 随任务展开，保持表达的分寸

- **内容决定结构。** 不为套模板硬凑三点、固定层数或页数；SCQA 用于确有铺垫需要的场景。
- **沟通保留自然。** 口头表达适配关系与情绪，故事保留需要的悬念，共情需要得到回应。
- **事实保留边界。** 计划仍是计划，假设仍需验证，数字与口径不因改写而变化。
- **交付尊重要求。** 只要提纲就不扩写全文；明确说“只要成稿”或要求严格格式时，不附教学。

PPT 能力提供内容结构、故事线与讲述设计；实际生成演示文件需要配合相应工具。事实核对依赖实际材料及可用工具，结构检查与事实核实各自说明范围。

## 安装与使用

支持 **Codex** 与 **WorkBuddy**。产品名为“思维架构师”，技能标识保持 `pyramid-studio`，已有安装与调用方式继续有效。

下载或克隆仓库后，安装到 Codex：

```sh
python3 scripts/install.py
```

安装到 WorkBuddy：

```sh
python3 scripts/install.py --destination ~/.workbuddy/skills
```

新开对应应用聊天，明确请求“使用思维架构师”，或在 Codex 中调用 `$pyramid-studio`。无需额外 API Key 或配套技能；外部查证与文件制作使用所在环境已有工具。
