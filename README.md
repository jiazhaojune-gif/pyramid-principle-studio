## 让观点有结构，让表达有依据

材料已经很多，表达需要清楚的答案；学习需要知道，这个答案是怎样组织出来的。

Pyramid Studio 从读者要回答的问题出发，提炼中心观点，把理由、步骤与证据放在合适的位置。围绕一个统一入口，覆盖从问题分析到文稿审阅的常见工作场景。

**结论先行　·　以上统下　·　归类分组　·　逻辑递进**

默认交付两部分：**能直接用的结果 + 一小段方法复盘**。复盘指出本次实际用到的原理、随附资料的章节线索、它如何体现在表达里，以及日常如何迁移。一次聚焦一个主要方法，避免把每次任务变成长课。

## 从思考，到表达

| 能力 | 带来的改变 |
| :--- | :--- |
| **邮件与汇报** | 提炼重点，让核心进展与判断先被看见。 |
| **报告与长文** | 组织观点，让理由和证据沿清楚的层次展开。 |
| **PPT 故事线** | 串联每页观点，让整场表达有一条连贯主线。 |
| **问题分析** | 界定现状与目标的差距，区分事实、假设和验证方向。 |
| **逻辑审阅** | 检查中心观点、上下支撑与同层分组，定位实际的结构问题。 |
| **日常迁移与方法理解** | 从约朋友、商量安排、请求帮助到工作汇报，用真实表达理解并练习方法。 |

## 形式服务于内容

**结构随材料生长。** 观点需要几层、理由需要几项，由问题和证据决定；不为了套模板硬凑三点。

**表达保留事实的分寸。** 计划仍是计划，假设仍需验证；重组材料时，保留原有数字、范围和确定程度。

**交付贴近真正的任务。** 先交付成稿、提纲或诊断，再附简短方法复盘。明确要求“只要成稿”或严格格式时，遵从限制。

**学习逐步走向独立。** 不以助手写得好来证明用户已经学会；看使用者能否用自己的话解释结构，并在另一件生活小事中自行运用。

## 一个入口，按需展开

`pyramid-studio` 是唯一需要安装的技能。写作、分析、审阅与来源核对的流程在同一目录内协作；章节、术语与案例按需读取。

各模块共享同一套结构规则与事实边界：分析时明确问题，写作时组织论证，审阅时检查支撑关系。参考案例用于理解方法，实际输出以当前任务的材料为依据。

无需额外 API Key 或配套技能。联网查证和实际生成演示文件，取决于 Codex 所在环境提供的工具。

下载或克隆仓库后，运行：

```sh

```

然后新开 Codex 聊天，调用 `$pyramid-studio`。
