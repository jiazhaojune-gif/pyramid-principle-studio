## 完成这次表达，积累下次的能力

金字塔表达工作室帮助你完成眼前的汇报、文稿或对话，也帮助你理解：这次用了什么原理，为什么这样组织，下次怎样自己运用。

每次默认交付：**一份清楚的表达，一小段有用的复盘。**

结果可以直接使用；复盘聚焦一个实际起作用的主要方法，连接对应章节，结合成稿解释原理，再给一个日常可迁移的提示。通常只有几句，需要深入时再展开。

**结论先行　·　以上统下　·　归类分组　·　逻辑递进**

## 让方法，在实践中变成自己的

| 核心能力 | 你会得到什么 |
| :--- | :--- |
| **清晰成稿** | 把材料组织成重点明确、理由有序的汇报、长文与故事线。 |
| **方法可辨** | 看见实际用到的原理，以及随附资料中对应的章节与框架。 |
| **原理讲明** | 对照自己的表达，理解为什么把这句话放前面、这些要点为什么属于一组。 |
| **日常迁移** | 把方法带进商量安排、解释选择、请求帮助和说明误会等生活对话。 |
| **逻辑审阅** | 检查主线、分组和支撑关系，找到最值得修改的地方。 |
| **渐进练习** | 按需从一句话开始练习，逐步减少代写，走向独立组织。 |

## 工作与生活，都有清晰表达的时刻

**工作中**：邮件、周报、项目汇报、报告方案、PPT 故事线、问题分析与审稿。

**生活中**：和家人商量安排、向朋友解释选择、提出请求、讲清误会、梳理一段经历。

表达适配对象、关系与场景：口头沟通保留自然语气，故事保留需要的悬念，情绪沟通保留理解与回应的空间。

[看看具体的呈现方式 →](docs/PRACTICE-EXAMPLES.md)

## 学习，最终体现为自己会用

清楚的成稿是眼前结果；能用自己的话解释组织方式，并在另一个情境中独立运用，是逐步内化的表现。

一次聚焦一个主要方法。练习按需进行，重复使用时减少重复讲解。明确要求“只要成稿”或严格格式时，优先遵从本次要求。

事实、计划与假设保留各自的分寸，表达的力量来自内容及其支持。

## 安装与使用

技能名：`pyramid-studio`。支持安装到 **Codex** 与 **WorkBuddy** 的个人技能目录。

下载或克隆仓库后，安装到 Codex：

```sh
python3 scripts/install.py
```

安装到 WorkBuddy：

```sh
python3 scripts/install.py --destination ~/.workbuddy/skills
```

新开对应应用的聊天即可开始使用。无需额外 API Key 或配套技能；联网查证与实际生成演示文件，依赖所在环境提供的工具。
