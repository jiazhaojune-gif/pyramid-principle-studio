# 金字塔表达工作室

想法很多，写出来却像流水账？把材料交给 Codex，调用 `$pyramid-studio`，让它先找到读者想知道的答案，再整理支持这个答案的理由和证据。

它可以帮你写邮件与周报、搭报告提纲、编排 PPT 故事线、拆解问题、检查原稿逻辑。你只需说明：给谁看、要回答什么、有哪些材料、想要什么形式。

例如：

```text
$pyramid-studio 把以下材料整理成给老板的周报，200字以内，只使用给定事实：……
```

也可以说：

```text
$pyramid-studio 帮我把这份报告改成10分钟汇报故事线，每页给观点标题、证据和讲稿要点：……
```

它将两份金字塔技能资料整合为一个入口，按任务调用对应模块；有现成稿就改结构，没结论就先整理问题与验证办法。它不会为了凑三点补数据，也不会把计划写成成果。来源核对依赖实际材料与可用工具。

安装：下载仓库、解压，在目录运行 `python3 scripts/install.py`，然后新开 Codex 聊天，输入 `$pyramid-studio` 即可。支持自动匹配相关任务，也可以每次明确调用。

一句话介绍：**让读者先看见答案，再看懂你的理由。**
