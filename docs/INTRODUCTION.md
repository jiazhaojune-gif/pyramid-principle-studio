# 思维架构师 · Pyramid Architect

**架构思考，驾驭表达。**

基于金字塔原理，贯通问题分析、论证构建、内容呈现与方法内化。完整支持短文与汇报、长文与报告、PPT故事线、问题与决策分析、逻辑审阅、来源与数据核对、日常沟通、方法学习与练习。

你可以交给它零散材料、未完成的文稿、难以讲清的问题或一次日常沟通。它从对方真正关心的问题出发，提炼中心判断、组织理由和证据，再按任务交付自然的口头表达、可使用的成稿、清楚的故事线或有依据的诊断。

方法内化贯穿每次实践：先给一份清楚的结果，再用几句话指认实际用到的原理与对应章节，结合成稿讲明为什么这样组织，给出日常可迁移的提示。一次聚焦一个主要方法，深入讲解与练习按需进行。

学习最终体现在使用者能自己解释结构，并在新的情境中独立运用。事实、计划与假设保持各自的分寸；故事和情绪沟通保留自然的节奏与语气。

支持 Codex 与 WorkBuddy。技能标识保持 `pyramid-studio`，已有调用继续有效。PPT侧重内容结构与故事线，文件制作和外部查证依赖环境中实际可用的工具。
