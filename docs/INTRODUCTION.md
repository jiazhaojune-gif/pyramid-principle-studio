# 金字塔表达工作室

**把清晰表达，练成自己的能力。**

融合金字塔原理、结构化思考与逻辑审阅，让每一次真实沟通，都成为理解与运用方法的机会。

它帮助你完成眼前的表达，也帮助你理解这次用了什么原理、为什么这样组织、下次怎样自己运用。每次默认先给一份清楚的结果，再附几句有针对性的方法复盘：连接对应章节，讲明原理，提示日常迁移。一次聚焦一个主要方法，深入讲解和练习按需展开。

清晰成稿、方法可辨、原理讲明、日常迁移、逻辑审阅与渐进练习，构成新版的六项核心支持。你可以用它组织邮件、周报、报告和PPT故事线，也可以用它商量安排、解释选择、请求帮助或讲清一段经历。

表达适配对象和关系，保留自然的语气；事实、计划与假设保留各自的分寸。学习最终体现在使用者能够自己解释组织方式，并把方法迁移到另一个真实场景。

支持 Codex 与 WorkBuddy。安装和示例见 USAGE.md。

**从用得上，到想得清，再到自己会。**
