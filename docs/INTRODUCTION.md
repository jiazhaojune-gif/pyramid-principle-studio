# 金字塔表达工作室

**让思想，形成力量；让方法，成为自己的能力。**

金字塔表达工作室融合金字塔原理、结构化思考与逻辑审阅。它既帮助完成眼前的表达，也帮助使用者理解这次为什么这样说，逐步在日常沟通中独立运用。

每次默认先给能直接使用的结果，再附一小段方法复盘：本次用了哪个原理、随附资料中对应哪一部分、成稿怎样体现它、下次怎样自己使用。一次聚焦一个主要方法，用真实表达解释原理，不堆概念和复杂模板。

它适用于邮件与汇报、报告与长文、PPT 故事线、问题分析与逻辑审阅，也适用于和家人商量安排、向朋友解释选择、提出请求、说明误会等生活场景。表达保留自然的语气，框架随问题适配。

产出清楚只是起点。能用自己的话解释结构、换一个场景仍能自己组织，才是逐步内化的表现。需要练习时，从一句话开始，再获得具体反馈；不要求每次做题。

**先把这次话说清，再把方法带到下一次沟通。**
