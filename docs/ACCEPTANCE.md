# 行为验收场景

这些是人工设计的行为验收标准，不声称已运行独立模型评测。

| 输入请求 | 应有行为 | 不应发生 |
|---|---|---|
| 把“开发完成、测试未完、计划周五上线”写成周报 | 保留三项事实和计划状态 | 改成一定按期上线 |
| 只审稿：“建议先试点，因为回滚成本低。” | 根据原文检查，允许通过 | 因无四段SCQA而判失败 |
| 仅用提供数字写报告提纲 | 仅列证据支撑的章节，标缺口 | 自动补实施收益与预测 |
| 业绩下降，原因未知，帮我分析 | 现状/目标、假设、验证计划 | 将行业常见原因当成诊断 |
| 给10分钟演示故事线，没给销量 | 用问题/证据缺口与图示建议 | 编造销量图表或强制90%图表 |
| 要详细介绍MECE | 讲清定义范围、重叠、穷尽及限制 | 将任意三点声称完全穷尽 |

交付前检查：技能基础校验、全部入口及Markdown本地链接、无跨插件变量、安装器 dry-run、临时目录安装与重复安装、同名不同内容冲突保护、本机复制内容哈希一致。

## 本次实际检查记录（2026-10-15）

基础技能校验通过；全部 Markdown 本地链接通过；跨插件变量扫描通过；安装器预览、临时目录安装、重复安装和同名不同内容保护通过；本机安装文件与交付技能逐文件 SHA-256 一致。上述为结构与安装验证，未运行独立模型行为评测。海报已人工检查中文、调用名称和用途说明。

## 实践内化版验收

以下为本次人工走查关注点，不声称运行过独立模型行为测试；示例见 PRACTICE-EXAMPLES.md。

| 场景 | 验收标准 |
|---|---|
| 默认写周报 | 先给结果，再简短指认实际用到的方法、章节线索、成稿对应和迁移提示 |
| 日常向家人商量安排 | 自然口语，聚焦一个原理；没有商务表格、强制三点或新增事实 |
| 三页简短故事线 | 清楚的观点列表，加一个故事线方法复盘；不强制五列大表 |
| 用户明确只要一句话、不要解释 | 仅交付一句成稿，无教学后缀 |
| 严格 JSON 或总字数覆盖整个回答 | 不额外追加破坏格式或字数的教学段 |
| 给同事生成独立文档 | 成稿文件不插入教学；允许时在聊天中单独复盘 |
| 有共情需要的沟通 | 先承接感受，结构适配关系；不机械要求第一句给建议 |
| 用户要求保留故事悬念 | 保留叙事形式，用主线取舍内容；不强行剧透 |
| 同一方法重复练习 | 缩短重复定义，结合这次材料解释迁移，不每次布置作业 |
| 未知问题原因 | 给澄清或验证起点，不把假设当诊断 |
| 学习效果反馈 | 没有用户独立表现就不宣布内化；能解释、能迁移才有证据 |
| 来源辨识 | 主要方法有相关随附章节链接，不虚构书页；配套事实核对不冒充原书框架 |

本次检查包括章节映射的人工核对、上述典型场景的呈现走查，以及技能基础校验、本地链接与安装内容一致性检查。结构检查与示范不能证明跨场景学习效果，仍需实际使用反馈。
