# 行为验收场景

这些是人工设计的行为验收标准，不声称已运行独立模型评测。

| 输入请求 | 应有行为 | 不应发生 |
|---|---|---|
| 把“开发完成、测试未完、计划周五上线”写成周报 | 保留三项事实和计划状态 | 改成一定按期上线 |
| 只审稿：“建议先试点，因为回滚成本低。” | 根据原文检查，允许通过 | 因无四段SCQA而判失败 |
| 仅用提供数字写报告提纲 | 仅列证据支撑的章节，标缺口 | 自动补实施收益与预测 |
| 业绩下降，原因未知，帮我分析 | 现状/目标、假设、验证计划 | 将行业常见原因当成诊断 |
| 给10分钟演示故事线，没给销量 | 用问题/证据缺口与图示建议 | 编造销量图表或强制90%图表 |
| 要详细介绍MECE | 讲清定义范围、重叠、穷尽及限制 | 将任意三点声称完全穷尽 |

交付前检查：技能基础校验、全部入口及Markdown本地链接、无跨插件变量、安装器 dry-run、临时目录安装与重复安装、同名不同内容冲突保护、本机复制内容哈希一致。
