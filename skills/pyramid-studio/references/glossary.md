# 术语表（按拼音/字母序）

> 释义为实践性概括，词条后标注主要出处章节。保留原书精确术语，未做同义替换。

| 术语 | 释义 | 出处 |
|------|------|------|
| **MECE原则** | 分组与划分的两条硬性要求：各部分相互独立（mutually exclusive，无重叠）+ 完全穷尽（collectively exhaustive，无遗漏）。诊断框架、逻辑树、结构顺序均建立在其上 | ch06, ch09 |
| **R1 / R2** | R1=非期望结果（现状，你不喜欢的结果或未抓住的机会）；R2=期望结果（目标，希望结构或流程产生的结果）。两者的差距即"问题" | ch08 |
| **S-C-Q（背景-冲突-疑问）** | 序言的故事结构三要素，加上回答（A）构成完整序言：背景→冲突→疑问→回答（金字塔塔尖思想） | ch02, ch04 |
| **程度顺序** | 重要性顺序，又称比较顺序：按共同特性归类的一组思想，按该特性的表现程度从强到弱排列 | ch06 |
| **封闭体系** | 一组相互独立、完全穷尽的行动性思想加上其产生的结果构成的体系：采取这些行动必然产生已说明的特定结果；流程中可能包含多层次的封闭体系 | ch07 |
| **骨架结构图** | 用几何图形（圆、直线、椭圆、矩形）+箭头概括抽象概念之间结构关系的图，替代无法"拍照"的具体图像 | ch12 |
| **归纳跃进** | 从一组具有共性的思想中提炼出其隐含意义的最后一步概括动作；发现句子结构共性只是准备，跃进才算完成思考 | ch07 |
| **归纳推理** | 把具有共同点的思想归类分组并概括其共性的推理方式；组内思想可用同一个单一名词表示；第二点是对第一点所建立范畴的补充而非评述 | ch05 |
| **关键句要点** | 又称要点、核心观点、一级结论、一级论点：关键句层次上的思想，既回答中心思想引发的新疑问，又呈现文章框架；必须是完整的思想、完整的句子，每个要点配一段微型引言 | ch02, ch04 |
| **归类分组** | 金字塔四原则之一：每一组中的思想必须属于同一逻辑范畴；自查法是看该组能否用单一名词（"建议""原因""问题"）概括 | ch01 |
| **记忆力图像** | 阅读时在脑中逐步成型的图像，随文章展开细节渐丰；理解与记忆的载体，回忆时提取的是图像而非字句 | ch12 |
| **结构顺序** | 用示意图、地图、图画或照片想象某事物时的顺序；前提是该事物已被MECE地划分为各部分；描述时自上而下、从左向右 | ch06 |
| **结构化分析** | 在收集资料前先建立诊断框架和逻辑树、提出假设、再有针对性地收集资料证明或推翻假设的分析方法（外展推理的应用） | ch09 |
| **结论先行** | 金字塔四原则之一：每篇文章只有一个中心思想，且放在文章最前面；先提出总结性思想，再提出被总结的具体思想 | ch01 |
| **金字塔结构** | 条理清晰的文章的必然形态：单一中心思想居塔尖，下层思想分组分层向上解释和支持，越往下越具体；思想间存在纵向（疑问-回答）、横向（演绎/归纳）和序言（讲故事）三种子结构 | ch01, ch02 |
| **困扰/困惑** | 现在、即将或未来发生的事件，打乱序幕中稳定的结构与流程，从而引发R1；来源分外部原因、内部原因、近期认识到的其他原因 | ch08 |
| **连续分析法** | 又称序列分析：是否有问题→问题在哪里→为什么→能做什么→该做什么的五连问；前两问答案构成序言，后几问答案构成金字塔思想 | ch08 |
| **逻辑递进** | 金字塔四原则之一：每一组中的思想必须按逻辑顺序排列；仅有的4种顺序为演绎顺序、时间（步骤）顺序、结构（空间）顺序、程度（重要性）顺序 | ch01, ch06 |
| **逻辑树** | 从逻辑上系统细分可能性以生成解决方案的树状工具；用于序列分析的第4、5步（能做什么/该做什么）；与诊断框架分工不同（一个找原因、一个出方案） | ch09 |
| **诊断框架** | 设想问题所在领域状况、揭示经营活动构成与相互关系的分析框架；三种建立方法：呈现有形的结构、寻找因果关系、归类分组；用于提出问题（找原因），配合是非问题起"判决性实验"作用 | ch09 |
| **思想** | 向受众发送新信息并引发受众疑问的语句；放入金字塔每个方框的内容；思想进文章的唯一理由是支持更高层次的思想（新闻不是思想） | ch02 |
| **外展推理** | 先提出假设、再寻找支持信息的推理技巧；一旦获得支持信息，过程即转为归纳推理；结构化分析问题的思维起点 | ch09 |
| **缺乏思想的句子** | 只说明下层思想属于哪一类、却不概括其精华的空洞概括句（如"该公司存在3个问题"）；对读者枯燥乏味，对作者掩盖思考不完整 | ch07 |
| **时间顺序** | 按行动顺序（第一步、第二步……）组织因果关系的思想组；主题句是要达到的结果；也用于描述按过程展开的现有结构 | ch06 |
| **是非问题** | 措辞上必须用"是/否"回答的问题（源于法律at issue）；正确的问法（"现有库存水平是否过高"）能确认或排除原因、宣告调研结束 | ch08, ch09 |
| **视觉朗诵** | 把金字塔逐条转成文字幻灯片再逐字念的伪演示方式；区别于真正的视觉演示 | ch11 |
| **序言** | 文章金字塔结构之外的讲故事部分：概述读者已知信息并引出其疑问；目的是提示而非告知；序言中不出现需要求证的信息（图表） | ch04 |
| **演绎推理** | 线性推理：第二个论点评论第一个论点的主语或谓语，第三个论点说明前两者同时存在时的隐含意义；向上概括以最后一步为主体；关键句层次尽量不用，宜下沉到段落层次且不超过4步2结论 | ch05 |
| **疑问-回答式对话** | 金字塔纵向关系机制：每个表述引发读者疑问，必须在其下一层次横向逐个回答；回答完一个分支回到关键句层次 | ch02 |
| **以上统下** | 金字塔四原则之一：每一层次的思想必须是对下一层次思想的总结概括；写作的主要活动就是这种抽象概括 | ch01 |
| **切入点/序幕** | 界定问题框架的第一个要素：问题产生的具体领域，由现有的结构和流程构成（戏剧开场的布景） | ch08 |
| **故事梗概** | 把金字塔转成演示文稿的中间形态：白纸分区代表每张幻灯片，按序言要素→关键句要点→下层论点排列，标注文字页/图表页 | ch11 |
