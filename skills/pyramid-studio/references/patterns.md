# 方法模式库

> 按使用阶段排列的完整模式索引。每个模式给出适用条件与操作骨架，细节见对应章节文件。

## 一、结构构建模式

### 模式1：自上而下法
- **何时用**：已知主题、读者疑问或答案中的任意多数
- **操作骨架**：画主题方框 → 设想读者主要疑问 → 写出回答 → 说明背景（无争议表述）→ 指出冲突 → 检查疑问与答案对应 → 证实答案 → 填写关键句要点 → 逐层向下展开疑问-回答对话
- **来源**：ch03

### 模式2：自下而上法
- **何时用**：主题、疑问、读者认知均不清楚；塔尖立不起来
- **操作骨架**：列出所有要点（优先从行动性思想下手）→ 找出逻辑关系（画因果链，常暴露漏项）→ 得出结论 → 倒推序言（主题→疑问→答案→背景→冲突→关键句）
- **来源**：ch03

### 模式3：短句还原检查法
- **何时用**：检查一组思想有无逻辑顺序、分组是否成立
- **操作骨架**：每句改写成只含主谓宾的短句 → 匹配/共同点的句子归组 → 选择适当顺序排列
- **来源**：ch06（附录3）

## 二、序言与开头模式

### 模式4：S-C-Q-A 故事结构
- **要素**：背景（读者已知、无争议、锁定时空）→ 冲突（推动情节的事件，归结为"接下来会怎么样"）→ 疑问（全篇唯一初始疑问）→ 回答（塔尖思想）
- **顺序变体**：标准式 S-C-A（平实）／开门见山式 A-S-C（直接）／突出忧虑式 C-S-A（施压）／突出信心式 Q-S-C-A（先声夺人）
- **长度控制**：通常2-3段；背景+冲突最多3-4段；与读者越熟越短，可短至一句话；不放图表等需求证的信息
- **来源**：ch04

### 模式5：发出指示式序言
- **S**=我们打算做X → **C**=需要你们做Y → **Q**=如何做Y → 回答=步骤。疑问可隐含，但作者动笔前必须向自己明确写出
- **来源**：ch04

### 模式6：请求支持式序言
- **S**=我们遇到问题 → **C**=已有解决方案、需要__经费 → **Q**=应该批准吗
- **关键句3+1标准理由**：①问题刻不容缓 ②此方案能解决（或是最优）③收益超过成本 ④还有额外好处（成立才写）
- **来源**：ch04

### 模式7：解释做法式序言
- **S**=必须做X（或你们目前用X）→ **C**=还未准备好（X不能正常工作）→ **Q**=如何改进
- **关键动作**：动笔前在纸上并排列出"现状流程"与"正确流程"，两个流程的差异直接决定关键句要点
- **来源**：ch04

### 模式8：比较选择式序言
- **S**=我们希望做X → **C**=有几种执行方案 → **Q**=哪种最合理
- **要点组织**：首选围绕评估标准写；推荐方案非每项最优时改为"选择C的原因+放弃A/B的原因"；围绕替代目标而非替代方案
- **来源**：ch04

### 模式9：咨询类序言（项目建议书/进度小结）
- **建议书**：S=你遇到问题 → C=决定请第三方 → Q=你是合适人选吗 → 关键句四件套：理解问题/合理方法/丰富经验/安排合理
- **进度小结**：S=我们告诉过你X → C=你要求调查Y，已完成 → Q=发现了什么
- **来源**：ch04

## 三、思考分析模式

### 模式10：界定问题框架
- **四要素**：切入点/序幕（结构与流程）→ 困扰/困惑（打乱稳定的事件）→ R1（非期望结果/现状）→ R2（期望结果/目标）；扩展要素：已采取的答案、待回答的疑问
- **转序言**：从左到右再向下；读者已知的最终事实=冲突
- **来源**：ch08

### 模式11：7种读者状况→疑问映射
1. 不知如何将R1变为R2 → "我们应该做什么"（关键词：改变）
2. 知道方案不确定对不对 → "是否应该这样做"
3. 知道方案不知怎么实施 → "应该如何做"（关键词：步骤）
4. 方案已实施但失败 → 追溯历史找真问题 → "我们应该做什么"
5. 多方案难选 → "应该选哪种方案"
6. 知道R1说不出R2 → "应该采用哪些战略"（关键句=制订战略的步骤）
7. 知道R2不知是否处于R1 → "我们存在问题吗"（标杆比对）
- **来源**：ch08

### 模式12：诊断框架（三种形式）
1. **呈现有形的结构**：画系统示意图/行业细分图/业务流程图，定位R1出在哪个环节
2. **寻找因果关系**：财务结构图（如投资回报率拆解）、任务结构树（财务要素变管理任务）、行动结构树（从非期望结果反推行动原因）
3. **归类分组**：按相似性分类可能原因；或选择结构树逐步"是/否"二选一，把业务流程摆在每个分叉点
- **纪律**：每层MECE；是非问题起判决性实验作用；两批收集资料（先建框架、后验假设）
- **来源**：ch09

### 模式13：逻辑树（方案生成）
- **何时用**：序列分析第4、5步（能做什么/该做什么）；缺行业洞察时的替代思考工具；检查成文文章的分支缺漏
- **操作骨架**：把成本/收入/机会按MECE细分到可计算的行动分支 → 计算收益 → 评估风险 → 定方案
- **来源**：ch09

### 模式14：工作表旋转法（思考演绎、表达归纳）
- **操作骨架**：素材分三列（调研结果/结论/建议）完整走一遍演绎 → 把工作表逆时针旋转90度：建议列升为关键句层次，结论与调研结果下沉
- **来源**：ch05

### 模式15：归纳跃进可视化
- **操作骨架**：把一组思想画成图（市场=圆圈、分散=切块、障碍=挡板）→ 图像暴露隐含结论 → 落成一句概括；推不出结论时检查是否误把演绎当归纳
- **来源**：ch07, ch12

## 四、呈现表达模式

### 模式16：5种书面呈现法
| 方法 | 适用 | 要点 |
|------|------|------|
| 多级标题法 | 长文 | 每种格式代表一个层次；同组标题同句型；每组标题前先介绍 |
| 下划线法 | 中短文 | 论点句≤12词；演绎≤4个、归纳≤5个论点；严格疑问-回答 |
| 数字编号法 | 需检索的文件 | 与多级标题配合；序言/总结/过渡段不编号 |
| 行首缩进法 | 备忘录 | 一篇只对一个层级使用；观点用相同句型 |
| 项目符号法 | 进度小结 | 行首缩进的变形 |
- **来源**：ch10

### 模式17：过渡四法
1. **讲故事**：缩小版S-C-Q引出每个关键句要点（只用双方认可的真实信息）
2. **承上启下**：上节关键词/短语/思想放进下节起始句，并与下节论点结合
3. **章节总结**：超长章节中途凝练复述论点与基调
4. **下一步措施**：需读者行动时专设一节，只写逻辑上理所当然的动作
- **来源**：ch10

### 模式18：演示文稿转换六步
序言写详细 → 故事梗概（白纸分区当幻灯片）→ 初定呈现方法 → 写每页讲稿 → 设计绘图 → 排练×N。图表90%+文字10%；图表标题=答案句；每页顶部一句话提示观点
- **来源**：ch11

### 模式19：图像化改写
- **操作骨架**：列出段落要点名词 → 画骨架图（几何图形+箭头）→ 图像翻译成一句直接陈述句 → 替换原段
- **何时用**：句子冗长、术语堆砌、读者"什么也没看见"的段落
- **来源**：ch12
