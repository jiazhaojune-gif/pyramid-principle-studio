# 速查表

## 一、演绎 vs 归纳选择决策树

```
要组织一组思想
│
├─ 这组思想只有一个论据支持上层观点？
│   └─ 是 → 只能用演绎（单链条因果：效率低→加班多→价格无优势
│            塔尖改写为"价格偏高是因为生产效率低"）
│
├─ 第2个思想是否评述第1个思想的主语或谓语？
│   ├─ 是 → 演绎链。继续问：
│   │     ├─ 该层次是关键句层次？
│   │     │   ├─ 塔尖思想与读者预期不同（读者先要why）？→ 允许演绎
│   │     │   ├─ 不先解释分析思路读者无法理解行动？→ 允许演绎
│   │     │   └─ 其他情况 → 改用归纳（工作表旋转法，ch05）
│   │     └─ 低层次/段落内 → 演绎可用，但≤4步、≤2结论，少插干扰信息
│   │
│   └─ 否（第2点只是在第1点的范畴里添成员）→ 归纳组。继续检查：
│         ├─ 能用一个单一名词概括全组吗（原因/步骤/问题…）？
│         ├─ 组内每个思想都符合该名词的定义吗？（不符合→剔除或移组）
│         ├─ 组内句子是同主语换谓语，还是同谓语换主语？
│         └─ 两者都不是且无共性 → 这是新闻，删掉或另寻关系
│
└─ 向上概括
    ├─ 演绎组：以最后一步为主体概括整条推理
    └─ 归纳组：说明共性隐含的意义（归纳跃进）；选能包含全组的最小范畴
```

## 二、序言常见模式对照

| 模式 | 背景 S | 冲突 C | 疑问 Q | 回答/关键句要点 |
|------|--------|--------|--------|----------------|
| **发出指示式**（要求或告诉某人做某事） | 我们打算做X | 需要你们做Y | 如何做Y？（可隐含） | 步骤 |
| **请求支持式**（经费/资源申请） | 我们遇到一个问题 | 已有解决方案，需__经费 | 应该批准吗？ | ①刻不容缓 ②方案能解决/最优 ③收益>成本 ④额外好处 |
| **解释做法式**（教读者解决问题） | 必须做X／目前系统是X | 还未准备好／系统失灵 | 如何改进？ | 现状流程与正确流程的差异点 |
| **比较选择式**（多方案取舍） | 我们希望做X | 有几种执行方案 | 哪种最合理？ | 围绕评估标准；或"选C的原因+弃A/B的原因" |
| **项目建议书**（咨询） | 你遇到一个问题 | 决定请第三方解决 | 你是合适人选吗？ | 理解问题/合理方法/丰富经验/安排合理 |
| **项目进度小结**（咨询） | 我们告诉过你X | 你要求调查Y，已完成 | 发现了什么？ | 调查发现 |

**顺序变体**（三要素齐全、缺一不可）：
- 标准式 S-C-A：平实陈述
- 开门见山式 A-S-C：答案先行为主
- 突出忧虑式 C-S-A：先给冲突施压
- 突出信心式 Q-S-C-A：先抛疑问掌控节奏

**长度红线**：常规2-3段；背景+冲突≤3-4段；熟人间可短至一句；序言中不得出现图表。

## 三、"缺乏思想"句子改造检查清单

中招信号：句子形如"存在3个问题""建议5项改革""有以下特点"。

- [ ] 1. 把每个下层句子砍到只剩主谓宾（删定状补、形容词副词）
- [ ] 2. 问：为什么只列这几条、不列其他条？共同特性是什么？
- [ ] 3. 是行动性思想（步骤/措施/建议）？
  - [ ] 每项行动的结果明确到可检验了吗（"明年1月15日前利润提高10%"级）？
  - [ ] 每组行动≤5个、且共同导向同一结果？
  - [ ] 概括句说明的是行动的**直接结果**，不是行动清单本身？
  - [ ] 行动层次分对了吗（时间上先行=同层；引出对方=低一层）？
  - [ ] 没有按"任务/目标/利益"分类（分类必重复）？
- [ ] 4. 是描述性思想（信息/观点/原因）？
  - [ ] 找到结构共性了吗（同主语看谓语、同谓语看主语、都不同看隐含思想）？
  - [ ] 概括选的是包含全组的**最小范畴**吗？
  - [ ] 完成归纳跃进、说出共性隐含的意义了吗？
  - [ ] 用新概括句反查：有没有漏掉的组、漏掉的步骤？
- [ ] 5. 新概括句能触发读者问"如何做到"/"为什么"吗？

## 四、成文前自查清单

**结构层**
- [ ] 全文只有一个中心思想，且位于塔尖、最先出现（结论先行）
- [ ] 每个上层思想都是下层思想的概括，不是重复（以上统下）
- [ ] 每组思想同范畴、能用单一名词命名（归类分组）
- [ ] 每组内部说得出排序理由：演绎/时间/结构/程度四选一（逻辑递进）
- [ ] 关键句层次优先归纳；演绎链≤4步、归纳组≤5项
- [ ] 每组不超过5个思想；超出就分层或细分

**序言层**
- [ ] 背景是无争议表述，读者读后只会说"对，那又如何？"
- [ ] 冲突直接引出那个唯一的初始疑问
- [ ] 序言只提示已知信息，无图表、无需求证的内容
- [ ] 每个关键句要点前有微型引言（缩小版S-C-Q）

**内容层**
- [ ] 没有缺乏思想的概括句（对照清单三逐条过）
- [ ] 每个思想进文章的理由：支持更高层次的思想（新闻不入文）
- [ ] 行动性思想的措辞明确到脑中能成像（无法判断达成的目标=没写清）

**呈现层**
- [ ] 标题呈现思想精髓而非类别（无"背景""发现""结论"式标题）
- [ ] 同组标题句型一致；每组标题前有介绍段
- [ ] 章节之间有过渡（讲故事/承上启下），连接的是思想不是章节动作
- [ ] 删掉标题后全文仍读得顺畅

**问题分析类文章附加**
- [ ] 问题已展开为序幕→困扰→R1→R2
- [ ] 确认读者处于7种状况中的哪一种，疑问与之匹配
- [ ] 是非问题来自导致R1的背景（不是客户的问题），可被"是/否"回答
- [ ] 诊断框架每层MECE；资料分两批收集（建框架一批、验假设一批）
