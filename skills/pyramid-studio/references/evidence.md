# 来源与数据边界

写前列出影响结论的事实、计算、推断与建议，写后逐项对照。默认在内部完成，用户要求或存在关键缺口时展示。

- 记录可定位的来源：提示中的事实序号/引句，文件页码、表格单元格或章节，网页标题、链接及日期。不存在的定位不补造。
- 用户给定事实可以用于按材料写作，但不等于独立验证；必要时用“根据提供材料”。没有查证就不写“已验证”。
- 保留数字、单位、时间、总体、分母、地域与限定词。重要计算用可用的计算器或代码重算；百分比和百分点分开。
- 事实、推断、建议分清。相关性不升级为因果，计划不改写为成果，意向不写成承诺，形容词也不能增强证据力度。
- 仅用指定材料时，不添加外部事实。一般任务需查新信息时使用实际可用的研究工具；没有工具就说明验证限制。
- 材料冲突时保留各自口径，不能择一拼成确定结论。证据不足的收益预测留为待验证假设，不能充当核心论据。
- 严格可追溯请求：为实质性主张设 C01 等标识，列来源与位置，交付前逐句映射。一个助手可分阶段完成核对；只有实际经过独立审查才能称为独立验证。不能据提示词承诺事实保证。

可选详细记录格式：主张｜类型｜来源位置｜已核验/仅材料支持/有冲突/待核验｜限制｜修订。参考 [source-integrity/strict-trace.md](source-integrity/strict-trace.md) 的记录思想，不要求其中跨代理调用流程。
